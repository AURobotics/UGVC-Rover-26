# Road Detector Package
package for detecting roads and doing computations in regard. </br>
contains 2 main ideas: pointclouds for white lanes and whit circles - potholes, and lane follower node that moves the robot along the road. </br>
each idea is used for a different approach in the autonomous driving architecture ideas </br>
NOTE: the second idea - lane follower node - uses the first idea as in its implementation

## Package Structure
```graph
road_detector/
├── config/
|   ├── lane_followe_params.yaml # parameters for lane follower node
|   ├── params_sim.yaml # parameters for road detector node in simulation 
|   ├── params_test.yaml # outdated 5alas
|   ├── params.yaml # parameters for road detector node in real life
|   ├── pointcloud_logger_params.yaml # parameters for pointcloud logger node
|   └── video_publisher_params.yaml # parameters for video publisher node
├── launch/
|   ├── all.launch.py # Launch file for all nodes in the package - lane follwer approach
|   ├── lane_follower_launch.py # Launch file for lane follower node in simulation
|   ├── road_detector_launch.py # Launch file for road detector package
|   └── road_detector_test_launch.py # Launch file for road detector with logger and video to test pointcloud values
└── road_detector/
    ├── cv_code/ # folder with cv implementation - contains its own README.md file
    ├── lane_follower_node.py # node for lane following using the pointclouds generated by the road detector node
    ├── mock_test_node.py # node for testing the lane follower node
    ├── pointcloud_logger_node.py # node for logging the pointclouds generated by the road detector node for testing purposes
    ├── road_detector_node.py # main node for road detection and lane following
    ├── video_publisher_node.py # node for publishing video feed of the camera detected lanes and potholes for testing purposes
    └── video_viewer.py # script for viewing the video feed published by the video_publisher_node for testing purposes
```
